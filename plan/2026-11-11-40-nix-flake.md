# Plan: Install and configure Flux on NixOS with a flake

Branch `feat/40-nix-flake`, issue #40. Steps 8–9 (hashes, builds,
commits) stay with the session model.

## Approved decisions (from the spec)

- Flake input: nixos-unstable only. Systems `x86_64-linux`, `aarch64-linux`.
- Packages: `flux-core` (Go: fluxd, flux-cli, flux-approve static, plugin,
  udev rule, desktop entry, icons, `lib/flux/bin/flux` link; nothing in
  `/etc`), `flux-gui` (Qt6, wrapQtAppsHook, qtbase qtdeclarative qtsvg
  qtwayland), `flux` = `default` = `symlinkJoin` of both.
  `apps.flux-cli`, `overlays.default`, `nixosModules.default`,
  `homeManagerModules.default`, `checks`, `formatter = nixfmt-rfc-style`.
- Version: `nix/version.nix` = `"0.19.1"`, plus `+${self.shortRev or "dirty"}`,
  passed as `-X main.version=` to fluxd and flux-cli.
- Go: `var packager = ""` in `cmd/flux`; `approve.HelperPath` becomes a
  `var`; flake sets `-X main.packager=nix` and
  `-X flux/internal/approve.HelperPath=<flux-core>/lib/flux/flux-approve`.
  Empty `packager` = today's behaviour exactly.
- fluxd is **never** wrapped (`internal/upgrade.Self` compares `argv[0]`
  with `/proc/self/exe`). `ExecStart` is the profile path
  (`/run/current-system/sw/bin/fluxd` or `${home.profileDirectory}/bin/fluxd`),
  `restartIfChanged = false` / `X-RestartIfChanged=false`; fluxd's watcher
  restarts it with exit 75 once idle.
- Unit body = `dist/fluxd.service` with `Type=exec` and
  `ExecReload=${coreutils}/bin/kill -HUP $MAINPID`.
- `runtimePackages` default: `pipewire pulseaudio ffmpeg wtype mpv
  gpu-screen-recorder wf-recorder libxkbcommon iproute2 openssh
  wl-clipboard xdg-utils`, added to system/home packages, not wrapped.
- NixOS `services.flux`: `enable`, `package`, `runtimePackages`, `users`
  (unit only for these, `ConditionUser=|<u>`), `openFirewall` (false; TCP
  12100–12108, UDP 12100), `webcam.enable` (false), `webcam.moduleOptions`
  (`"devices=0"`, nullable), `approve.services` (PAM rule just before
  `pam_unix`). Avahi `enable`/`publish.enable`/`publish.userServices` as
  `mkDefault true`. udev via `services.udev.packages`.
- Home Manager `services.flux`: `enable`, `package`, `runtimePackages`,
  `plugin.enable` (true; copy once if missing, fluxd keeps it current).
- Settings in `~/.config/flux` stay user-managed. Security findings from
  the review are separate issues.

## Rollback

Revert the branch's commits (or don't merge the PR). Nothing touches a host;
the Go changes are inert with an empty `packager`. A host that enabled the
module removes `services.flux` from its config and rebuilds.
